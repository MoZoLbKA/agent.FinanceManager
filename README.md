## 📖 О проекте

**Finance Manager Agent** — это модульное решение для автоматизации личных финансов. Система разделена на три независимых компонента, каждый из которых отвечает за свою задачу и может использоваться как отдельно, так и в связке.

*   **🧠 Agent** — ядро бизнес-логики: обработка транзакций, расчёт статистики, работа с базой данных.
*   **🤖 Telegram Bot** — пользовательский интерфейс в удобном мессенджере.
*   **🌐 Web API** — RESTful интерфейс для интеграции с веб-приложениями, мобильными клиентами или внешними сервисами.
